# HandyMath 0.2 验证记录（2026-10-12）

## 笔迹问题的复现与修复

用户已在 HarmonyOS 4.0 + M-Pencil 上确认笔/手指区分和笔输入工作，但反馈延迟、扁形笔触、旋转拉伸。

旧版回归命令：

```powershell
adb -s emulator-15554 shell am instrument -w -e regression true com.handymath.app.test/com.handymath.app.MathInstrumentation
```

在旧 APK 上实测失败：`round tip deformed: width/height=1.375`。原实现分别使用 `width/1000` 和 `height/1400` 变换，使圆形笔尖成为椭圆，也让笔迹随窗口比例改变。

旧代码每帧创建全屏 `saveLayer`，重放全部历史点，且在主线程序列化/写入整个草稿。新版使用 dp 世界坐标、单一缩放因子、增量分区缓存与后台保存队列。

修复后圆形笔尖检查和旋转后的像素宽高比例检查通过。相同 50,000 报点的预热软件 Canvas 基准两次结果：

| 基准 | 旧版 | 新版 |
|---|---:|---:|
| 第一次 | 74.32 ms/帧 | 0.18 ms/帧 |
| 第二次 | 82.60 ms/帧 | 0.24 ms/帧 |

这些数字测量模拟器软件绘制，不包含手写笔传感器、触屏驱动、Android 合成与物理显示延迟。真机是否充分跟手仍需复测。旧版基准仅保留在测试 APK 的 `LegacyInkView`，不会进入主 APK。

## 功能验证

- Gradle `assembleDebug`、`assembleDebugAndroidTest` 成功，Android Lint 无错误。
- 基础 instrumentation：5 题及图片/Markdown 题库、评分格式与边界、第四级提示、Key 加密、默认不让手指落笔、笔输入、撤销/重做、取消笔画、草稿恢复、有效 ZIP 导入、越界 ZIP 拒绝及失败不切题库、复习间隔均通过。
- 全文档导出：将视口移动到完全看不到原笔迹的位置，仍能从冻结文档导出原笔迹；不依赖视口截图。
- 几何回归：固定压感圆点在方形视口和横屏视口均保持圆形，旋转不改变统一缩放因子。
- UI instrumentation：启动为题库首页；横屏画布宽度占题目+画布的约 60%；点击题库后继续最近题目。
- 实际 Android WebView：第五题离线 KaTeX 渲染成功；Markdown 粗体与行内公式同时渲染；注入的 `<script>` 被净化且不执行。
- 实际 UI 已检查竖屏、横屏及第五题公式。圆形图标工具栏、增大的横线行距与独立图片查看器已实现。
- 源码和主 APK 的 Key 格式扫描通过，不含提供的调试 Key。

## 批改链路

旧版除了依赖单次模型判断，也可能继续显示修改笔迹前的旧评分。新版编辑笔迹立即隐藏并失效旧评分，旧版本不带独立转写的评分不会继续作为当前评分展示。

识别器只看学生图片；评分器比较独立转写与题面/解析；选择题执行标准选项一致性检查；拟满分再进行不看参考解析的独立核验。结果始终显示转写与针对性点评。

真实 DeepSeek `deepseek-flash` 安卓端测试已通过图片识别检测、4 次分层提示、手写错误 B 的部分引导及非满分评分、手写正确 C 的满分评分。测试还发现只写单字母 C 时 `choice` 有时为空，已对明确单字母的 `finalAnswer` / `transcription` 归一化，避免误判为未作答。

还观察到模型点评误把 $2n\pi$ 当成整数。对于第一题仅写 C 的情况，题库已提供人工核对的依据 $2n\pi-1<\lfloor2n\pi\rfloor\le2n\pi$，不再采用模型临时生成的这个证明。其它复杂作答的点评仍需要用户核对。

第五题的正确极限为 $-4/\pi^2$。新增真实网络回归以 `+4/pi^2` 为学生答案，已通过：错误正号未被判为正确负号，并返回针对性反馈。最终真实端到端测试包含这一检查并全部通过。模型仍有识别/推理误差，多阶段核验降低错误满分风险，但不构成准确率保证；用户应核对显示的转写。

## 真机复测建议

1. 连续写满一屏及拖动画布继续写，观察是否还越写越慢或周期性停顿。
2. 分别横写、竖写、斜写同样压力的线，检查粗细；轻压/重压应改变宽度。
3. 横屏写圆/正方形，旋转竖屏并来回切换，检查形状与草稿保存。
4. 单指拖动、双指缩放，再用笔书写；手掌贴屏时应不产生笔迹或拖动。
5. 橡皮悬停/擦除时检查范围圈，撤销擦除应恢复笔迹和原位置。
6. 将部分答案写在可见范围以外，提交后确认转写覆盖那些步骤。
7. 第一题写 B；第五题写 $+4/\pi^2$ 或有明显错误的推导，确认不会给满分，并核对智能点评。
8. 首页重新点击题库后应回到该题库最近练习的题目，图片查看器可缩放、拖动、双击复位。

华为系统双击、真实压感及硬件端到端延迟无法在普通 Android 模拟器完整验证。厂商预测、一笔成形和前缓冲 SDK 本次未接入。
